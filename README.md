# Beneath Enchanted Sky (BES) — Unity MVP

Action RPG MVP focused on **Story + Quest + AI NPC + Open World demo** (3-month backlog).

## Quick Start
1. Open in **Unity 6000.3 LTS**
2. Menu: **BES → Setup Project (US-001 to US-006)**
3. Play `Assets/_Project/Scenes/MainMenu.unity`

## MVP Features
- Third-person movement (walk, sprint, jump, dodge)
- Combat (basic attack, 2 skills, enemy + boss)
- AI NPC dialogue with memory and affinity
- Quest system with branching and endings
- 3 demo regions with collectibles and teleport
- Save/Load JSON persistence
- HUD, Dialogue UI, Inventory UI
