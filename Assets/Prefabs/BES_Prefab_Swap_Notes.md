# BES Prefab Swap Notes

The generated island scene uses existing asset-pack prefabs directly where possible and procedural placeholders where final game-specific prefabs are not imported yet.

Recommended future prefab swaps:
- Replace NPC capsules with final BES character prefabs.
- Replace deer/rabbit placeholders with animated animal prefabs.
- Replace procedural birds with final flocking bird prefabs if available.
- Convert recurring generated props into reusable modular prefabs after visual approval.
